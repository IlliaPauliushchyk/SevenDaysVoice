# SevenDaysVoice

Локальная озвучка мода «7 Дней Лета: Lost Alpha» для «Бесконечного лета». Проект лежит отдельно от каталога Steam.  Голоса создаются на вашем компьютере, без интернета во время самой озвучки.

Игра и мод при установке только читаются. В папку Steam ничего не копируется, пока вы сами не запустите `install_integration.bat` в конце.

Рабочая модель — Silero v5.6. У неё пять дикторов: `aidar`, `eugene`, `baya`, `kseniya`, `xenia`. Примеры в файлах ниже — это уже заполненная настройка этого компьютера. На другом компьютере пути к игре нужно вписать свои.

## Что должно уже стоять

1. Игра «Бесконечное лето» из Steam.
2. Мод «7 Дней Лета: Lost Alpha» из мастерской Steam. В его папке должна быть папка `scenario_alt`.
3. Свободное место на том же диске, где лежит эта папка проекта. Готовые голоса пишутся сюда, в `generated_audio\voice`. Полный сюжет мода занимает много часов и много гигабайт. Эту папку в проводнике лучше не открывать: файлов слишком много, и окно может зависнуть.
4. Видеокарта NVIDIA. Скрипт установки ставит PyTorch под CUDA 12.4. Если в конце установки будет `CUDA True`, карта видна и генерация пойдёт на ней.

Интернет нужен один раз: при `setup.bat` и при первой загрузке кода модели. Когда окно генерации уже пишет голоса, минута без сети его не останавливает.

## Как запускать файлы .bat

Все команды ниже — это файлы в корне проекта, рядом с этим README. Например, полный путь на этом компьютере: `V:\SevenDaysVoice\setup.bat`.

Дважды щёлкните файл. Откроется чёрное окно. Пока оно работает, компьютер лучше не уводить в сон и само окно не закрывать.

Если окно мигнуло и сразу исчезло, откройте его так, чтобы текст остался на экране:

1. Откройте папку проекта в проводнике.
2. Щёлкните адресную строку, впишите `cmd` и нажмите Enter.
3. В появившемся окне впишите имя файла, например `setup.bat`, и нажмите Enter.

Дальше шаги идут по порядку. Следующий запускайте, когда предыдущий дописал свою последнюю строку и вернул приглашение ввода.

## Шаг 1. Поставить Python 3.12

Python — программа, на которой работает генератор. Нужна именно версия 3.12. `setup.bat` ищет её только в двух местах:

- `%LocalAppData%\Programs\Python\Python312\python.exe`
- `%ProgramFiles%\Python312\python.exe`

`%LocalAppData%` на этом компьютере обычно выглядит как `C:\Users\Имя\AppData\Local`.

Команду установки вводят в чёрном окне консоли. Папку проекта для этого открывать не нужно.

1. Нажмите клавишу Windows на клавиатуре. Откроется поиск.
2. Наберите `cmd`.
3. В списке выберите «Командная строка» и нажмите Enter. Откроется чёрное окно с мигающим курсором.
4. Щёлкните внутри этого окна, вставьте команду ниже и нажмите Enter. Вставить текст в консоль можно правой кнопкой мыши или сочетанием Ctrl+V.

```bat
winget install --id Python.Python.3.12 -e
```

5. Если Windows спросит «Разрешить этому приложению вносить изменения?», нажмите «Да».
6. Дождитесь, пока внизу окна снова появится строка с мигающим курсором. Пока бегут проценты и строки про загрузку, окно не закрывайте.

Если `winget` пишет, что Python 3.12 уже установлен, этот шаг можно пропустить и закрыть окно.

Если установщик python.org ставится вручную, на первом экране оставьте путь по умолчанию. Для `setup.bat` галочка «Add python.exe to PATH» не обязательна: он сам находит файл по путям выше.

## Шаг 2. Запустить setup.bat

Дважды щёлкните `setup.bat`. Он делает сразу несколько вещей и на это уходит время:

- создаёт папку `venv` — отдельный Python только для этого проекта;
- скачивает PyTorch и остальные библиотеки из `requirements.txt`;
- подключает сам проект.

После `setup.bat` папки `models\torch\hub\snakers4_silero-models_master` и файла `v5_6_ru.pt` ещё нет. Этот скрипт ставит только Python-библиотеки. Сам файл модели появляется позже, при первом запуске генерации. Куда он ляжет, написано в шаге 6.

В конце окна должны быть две строки:

```text
CUDA True
Окружение готово. Дальше: analyze.bat
```

`CUDA True` значит, что видеокарта доступна. `CUDA False` значит, что генерация пойдёт через процессор и будет намного медленнее. Тогда проверьте, что драйвер NVIDIA установлен, и запустите `setup.bat` ещё раз.

Повторный запуск `setup.bat` безопасен: папка `venv` создаётся один раз, пакеты ставятся заново.

## Шаг 3. Прописать пути в config/paths.json

Это обычный текстовый файл. Его можно открыть Блокнотом. Программа читает из него два поля:

- `game_path` — папка самой игры «Бесконечное лето»;
- `mod_path` — папка мода «7 Дней Лета: Lost Alpha».

Готовые файлы `.ogg` всегда пишутся в папку `generated_audio` внутри проекта. Путь к ней в `paths.json` не задаётся: программа сама берёт папку рядом с этим README.

Внутри лежит `generated_audio\voice\`. Дальше имя реплики режется на две буквы, и файл кладётся в такую подпапку:

`generated_audio\voice\{первые два символа идентификатора}\{идентификатор}.ogg`

Например, реплика `alt_day0_start_d_b4e7a886` попадает в `generated_audio\voice\al\`, потому что её идентификатор начинается с `al`. Это буквы идентификатора, а не ключ персонажа Альки.

Папка `generated_audio\voice` очень большая: в ней сотни тысяч мелких файлов. В проводнике её лучше не открывать. Окно может долго думать и зависнуть. Чтобы понять, что генерация идёт, щёлкните правой кнопкой по `generated_audio`, выберите «Свойства» и посмотрите, растёт ли размер. Внутрь `voice` заходить не нужно.

Как найти папку игры в Steam: библиотека → «Бесконечное лето» → шестерёнка → «Управление» → «Просмотреть локальные файлы». В адресной строке проводника будет путь. Его и вписывают в `game_path`.

Мод мастерской для этой игры лежит рядом, в `steamapps\workshop\content\331470\`. Номер `441054187` — это «7 Дней Лета: Lost Alpha». Внутри должна быть папка `scenario_alt`. Если её нет, мод ещё не скачался: откройте его страницу в мастерской и дождитесь загрузки.

В JSON каждая обратная косая черта пишется дважды: `V:\\Steam\\...`. Кавычки и запятые оставляйте как в примере.

Текущий файл этого компьютера:

```json
{
  "game_path": "V:\\Steam\\steamapps\\common\\Everlasting Summer",
  "mod_path": "V:\\Steam\\steamapps\\workshop\\content\\331470\\441054187"
}
```

Сохраните файл в кодировке UTF-8. Блокнот Windows 10 при «Сохранить как» показывает кодировку внизу окна.

## Шаг 4. Выбрать движок в config/tts.json

Пока `engine` пустой или `chosen_by_user` не равен `true`, `generate_voices.bat` останавливается и файлы не пишет. Так сделано специально, чтобы случайный двойной щелчок не начал многочасовую генерацию. Модель из шага 6 без этой настройки тоже не скачивается.

Текущий файл:

```json
{
  "engine": "silero",
  "chosen_by_user": true,
  "scope": "scenario",
  "notes": "Основная озвучка — Silero v5.6 (v5_6_ru): русские дикторы, вопросы, восклицания и омографы. В базе строки помечены silero:v5_6_ru, чтобы файлы v4 перезаписывались."
}
```

Что означает каждое поле:

- `engine` — какая программа говорит. Для этой озвучки здесь стоит `silero`.
- `chosen_by_user` — подтверждение, что движок выбран руками. Должно быть `true`.
- `scope` — какую часть мода озвучивать. `scenario` — основной сюжет мода, папка `scenario`. «Старая дорога» (`old_road`) и оригинальная новелла в эту очередь не входят.
- `notes` — заметка для человека. Генератор её не читает.

В базе удачная строка помечается `silero:v5_6_ru`. Если у строки другая метка, следующий полный прогон соберёт её заново в тот же файл ogg.

## Шаг 5. Назначить голоса в config/voices.json

Имена дикторов берутся только из пятёрки Silero v5.6: `aidar`, `eugene`, `baya`, `kseniya`, `xenia`. Другое слово в этом файле модель не произнесёт.

Кто какой голос получает:

- пустой рассказчик и метка `narrator` читают `narrator_voice`;
- мысли `th` читают `thoughts_voice`;
- персонаж из списка `characters` читает свою строку;
- кто в список не попал, получает `default_voice`. Сейчас так остаётся служебная метка `extend`.

## Шаг 6. Файл модели Silero

Модель — один файл с весами дикторов. Отдельной строки «скачать модель» в настройках нет, и `setup.bat` его не кладёт. После шагов 4 и 5 файл появляется сам при первом запуске `generate_voices.bat`, пока окно грузит модель.

К этому моменту программа создаёт длинную папку и скачивает туда файл:

`models\torch\hub\snakers4_silero-models_master\src\silero\model\v5_6_ru.pt`

От корня проекта это выглядит так:

`V:\SevenDaysVoice\models\torch\hub\snakers4_silero-models_master\src\silero\model\v5_6_ru.pt`

Пока `generate_voices.bat` ещё ни разу не запускали, этого пути на диске нет. Искать его сразу после `setup.bat` не нужно.

Размер рабочего файла — 147664410 байт. В свойствах файла в проводнике это около 140 МБ. Если размер другой, файл скачался не целиком.

Папка `models\` в git не входит. При копировании проекта на другой компьютер её нужно скопировать вместе с проектом, иначе голоса на новом месте не из чего собирать.

Если папка кэша уже есть и `v5_6_ru.pt` на месте, первый запуск генерации пишет `Using cache found in ...\models\torch` и из сети файл не берёт.

Если папки `models\torch\hub\snakers4_silero-models_master` ещё нет, первый запуск сам забирает код Silero с GitHub. Сам `.pt` он пытается скачать с адреса из кэша Silero: `https://models.silero.ai/models/tts/ru/v5_6_ru.pt`. С части компьютеров этот адрес обрывается по таймауту. Тогда файл нужно положить в папку выше вручную. Откуда взят файл на этом компьютере, записано в `models\licenses\silero_weights_source.txt`. Текст лицензии — `models\licenses\silero_LICENSE.txt`.

Жёлтая строка `SyntaxWarning: invalid escape sequence '\^'` появляется из кода модели. На голос она не влияет, окно закрывать из-за неё не нужно.

Кэш torch и Hugging Face программа держит внутри проекта: `models\torch` и `models\huggingface`.

## Шаг 7. Собрать список реплик: analyze.bat

Дважды щёлкните `analyze.bat`. Он читает уже скомпилированные файлы мода `.rpyc` и записывает список реплик в `data\catalog.sqlite`. Рядом появляется `analysis_report.md` — короткий отчёт, сколько строк нашлось.

Игру и мод этот шаг не меняет. Файлы `.rpy` мода заново компилировать нельзя: игра перезапишет свои `.rpyc`.

Если `setup.bat` ещё не запускали, окно напишет `Сначала запустите setup.bat` и закончится.

Повторный `analyze.bat` нужен, если мод обновился и в сценарии появились новые реплики.

## Шаг 8. Сгенерировать голоса

Когда шаги 1–7 сделаны, дважды щёлкните `generate_voices.bat`.

Сначала окно несколько минут грузит модель. Потом может появиться строка про кэш и жёлтое предупреждение из шага 6. Дальше окно часто молчит. Это нормально: удачные реплики на экран не печатаются. Файлы при этом пишутся в `generated_audio\voice\`, как описано в шаге 3. Саму папку `voice` в проводнике не открывайте: файлов слишком много, и проводник может зависнуть. Хватает «Свойств» у `generated_audio`: размер должен расти.

Полный сюжет — это примерно сутки. Компьютер на это время лучше не уводить в сон. Закрытая крышка ноутбука часто включает сон и обрывает работу.

Остановить прогон можно клавишами Ctrl+C в чёрном окне. Уже записанные ogg остаются на диске. Если Windows спросит `Terminate batch job (Y/N)?`, ответьте `Y`.

Продолжение — тот же `generate_voices.bat` или `resume_generation.bat`. Второй файл просто вызывает первый. Уже готовая реплика пропускается, если одновременно совпали текст, голос, метка `silero:v5_6_ru` и файл ogg на диске. Второе окно генерации рядом запускать не нужно: оба пишут в одну базу `data\catalog.sqlite`.

Если в `config/voices.json` поменяли мужские голоса, переозвучить только их можно файлом `regen_male_voices.bat`. Он заново собирает реплики Семёна, «Я», рассказчика, мыслей, хора и остальных мужских ролей из шага 5. Женские роли он не трогает. Запускайте его, когда окно `generate_voices.bat` закрыто: открытый полный прогон держит старые голоса в памяти и пишет в те же файлы.

Английские строки и строки из одной точки модель пропустить не может. Они остаются без файла, в игре эти реплики молчат, остальные идут дальше.

## Шаг 9. Послушать в игре

Дважды щёлкните `play_voiced.bat`. Он открывает «Бесконечное лето» и подсказывает игре, где лежат голоса. В каталог игры при этом ничего не копируется.

Кнопка Play в Steam этот запуск не повторяет. Чтобы слышать новые файлы, игру закрывают и снова открывают через `play_voiced.bat`.

Игра произносит только ту реплику, чей ogg уже лежит в `generated_audio`. Остальные идут молча, пока генерация до них не дойдёт. Пока текст листается с зажатым пропуском, голос не играет.

### Громкость озвучки

**Громкость озвучки задаёт ползунок «Эмбиент» в настройках звука игры.** Если голос тихий, сдвиньте этот ползунок вправо. Уже готовые файлы из-за этого заново собирать не нужно.

## Шаг 10. Обычный запуск из Steam

Этот шаг необязательный. Пока хватает `play_voiced.bat`, каталог игры можно не трогать.

Когда проверка устроила, запустите `install_integration.bat`. Окно попросит подтверждение. Нужно ввести маленькими или большими буквами `da` и нажать Enter. Любой другой ответ отменяет установку.

В каталог игры добавляются только два новых файла:

- `game\sdv_autoload.rpy`
- `game\sdv_voice_path.txt`

Сценарии мода, сохранения и архив игры остаются как были. Сами ogg по-прежнему лежат в `generated_audio` проекта.

`rollback.bat` удаляет только эти два файла и возвращает игру к запуску без этой озвучки.

## Если что-то пошло не так

Окно пишет `Не найден Python 3.12`. Вернитесь к шагу 1 и проверьте, что файл `python.exe` лежит в одном из двух путей, которые ищет `setup.bat`.

Окно пишет `Сначала запустите setup.bat`. Папки `venv\Scripts\python.exe` ещё нет. Запустите шаг 2 и дождитесь строки «Окружение готово».

Окно пишет, что каталог игры или мода не найден. Откройте `config\paths.json` и проверьте `game_path` и `mod_path`. Путь должен открываться в проводнике, а в папке мода должна быть `scenario_alt`.

Окно генерации сразу заканчивается и файлов нет. Откройте `config\tts.json`: `engine` должен быть `silero`, `chosen_by_user` — `true`.

Генерация зависла на скачивании модели. Проверьте, что файл `v5_6_ru.pt` лежит по пути из шага 6 и его размер 147664410 байт.

В игре тишина на новой реплике. Файл для неё ещё не собран, либо игра запущена кнопкой Steam. Откройте игру через `play_voiced.bat` и дайте генерации дойти до этого места сюжета. Папку `generated_audio\voice` для проверки не открывайте.
